# Драйвер мыши с акселерацией

Драйвер для Linux, который меняет DPI мыши в зависимости от скорости движения.

## 🎯 Как работает

**Идея:** Медленное движение = точность, быстрое движение = скорость

- **Медленно** (< 200 пикс/сек) → DPI = 50% (точность)
- **Средне** (200-800 пикс/сек) → DPI = 100% (нормально)
- **Быстро** (> 800 пикс/сек) → DPI = 200% (скорость)

## 📦 Сборка

```bash
make
```

## 🚀 Установка

```bash
# Загрузить драйвер
sudo insmod mouse_accel.ko

# Посмотреть логи
dmesg | tail -50

# Выгрузить драйвер
sudo rmmod mouse_accel
```

## 🧪 Тестирование

1. Загрузи драйвер: `sudo insmod mouse_accel.ko`
2. Открой логи в отдельном терминале: `dmesg -w | grep mouse_dpi`
3. Двигай мышью:
   - **Медленно** - увидишь `CHANGE 100% -> 50%`
   - **Быстро** - увидишь `CHANGE 50% -> 200%`
4. Выгрузи: `sudo rmmod mouse_accel`

## 📊 Пример логов

```
mouse_dpi: CHANGE 100% -> 50% (speed=150 px/s)
mouse_dpi: CHANGE 50% -> 200% (speed=1200 px/s)
mouse_dpi: CHANGE 200% -> 100% (speed=500 px/s)
```

## 🛠️ Как это работает (для объяснения)

1. **Перехват событий** - драйвер ловит все движения мыши
2. **Расчет скорости** - считаем: расстояние ÷ время
3. **Определение DPI** - выбираем 50%, 100% или 200%
4. **Масштабирование** - умножаем dx/dy на DPI
5. **Отправка** - передаем в виртуальную мышь

## ⚙️ Настройка

В файле `mouse_accel.c` можно изменить пороги:

```c
#define SPEED_SLOW  200    // Граница медленно/средне
#define SPEED_FAST  800    // Граница средне/быстро
```

## 🐛 Отладка

Если не работает:

```bash
# Проверь, что драйвер загружен
lsmod | grep mouse_accel

# Проверь, что мышь подключена
cat /proc/bus/input/devices | grep -A 5 Mouse

# Посмотри полные логи
dmesg | grep mouse_dpi
```
